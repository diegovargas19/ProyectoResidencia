1. Introduccion

El Sistema de Gestion de Proyectos Academicos permite administrar proyectos de investigacion, equipos de trabajo, archivos de evidencia, encuestas, resultados y reportes institucionales desde una plataforma centralizada.

El objetivo del sistema es facilitar el seguimiento de proyectos academicos, organizar la participacion de investigadores y colaboradores, conservar documentos relacionados con cada investigacion y generar informacion util para la toma de decisiones.

Este manual esta dirigido a usuarios finales. No requiere conocimientos de programacion.

2. Roles de usuario

El sistema trabaja con distintos roles. Cada rol tiene permisos diferentes.

Administrador

El administrador tiene acceso completo al sistema. Puede:

  • Crear, editar y eliminar proyectos.
  • Asignar uno o varios investigadores a un proyecto.
  • Asignar cualquier cantidad de colaboradores a un proyecto.
  • Crear usuarios.
  • Editar usuarios y roles.
  • Administrar encuestas.
  • Consultar dashboard, resultados y reportes.
  • Descargar reportes.
  • Eliminar archivos cuando sea necesario.

Investigador

El investigador participa en proyectos asignados. Puede:

  • Ver sus proyectos asignados.
  • Consultar el detalle de cada proyecto.
  • Subir archivos y evidencias a sus proyectos.
  • Crear colaboradores.
  • Asignar hasta 3 colaboradores a los proyectos donde participa.
  • Consultar encuestas, dashboard y reportes si la navegacion de su perfil lo permite.

Colaborador

El colaborador apoya el trabajo de investigacion en proyectos especificos. Puede:

  • Ver la seccion Mis proyectos.
  • Entrar solo a los proyectos a los que fue asignado.
  • Subir archivos y evidencias en esos proyectos.
  • Ver y descargar archivos de sus proyectos asignados.

El colaborador no puede ver proyectos donde no participa.

Visor

El visor es un rol de consulta basica. Su acceso depende de la configuracion interna del sistema. Normalmente se utiliza para usuarios que requieren revisar informacion sin modificarla.

3. Inicio de sesion

Para entrar al sistema:

1Abra la pagina del sistema.

2Escriba su correo electronico.

3Escriba su contrasena.

4Presione el boton para iniciar sesion.

Si los datos son correctos, el sistema mostrara la pantalla principal.

Si aparece un mensaje de error:

  • Revise que el correo este escrito correctamente.
  • Verifique que la contrasena sea la correcta.
  • Si el problema continua, solicite apoyo al administrador.

4. Navegacion general

Despues de iniciar sesion, el sistema muestra una barra de navegacion superior.

Las opciones pueden variar segun el rol del usuario:

  • Proyectos o Mis proyectos.
  • Encuestas.
  • Dashboard.
  • Reportes.
  • Administracion.
  • Cerrar sesion.

En dispositivos pequenos, las opciones pueden aparecer dentro de un menu desplegable.

Para salir del sistema, use la opcion Cerrar sesion.

5. Proyectos y Mis proyectos

La seccion Proyectos o Mis proyectos es la pantalla principal del sistema.

Para administradores

El administrador ve la seccion Proyectos. Desde ahi puede consultar todos los proyectos registrados.

Puede:

  • Buscar proyectos por nombre, estado, prioridad, departamento, investigador o colaborador.
  • Crear un nuevo proyecto.
  • Editar un proyecto existente.
  • Eliminar un proyecto.
  • Entrar al detalle de un proyecto.

Para investigadores y colaboradores

Los usuarios asignados a proyectos ven la seccion Mis proyectos.

Esta vista muestra unicamente los proyectos donde el usuario participa como investigador o colaborador.

Tabla de proyectos

La tabla muestra informacion como:

  • Nombre del proyecto.
  • Investigadores asignados.
  • Colaboradores asignados.
  • Departamento.
  • Estado.
  • Prioridad.
  • Fecha limite.
  • Acciones disponibles.

La tabla cuenta con paginacion para mantener la pantalla ordenada cuando existen muchos proyectos.

6. Crear o editar un proyecto

Esta funcion esta disponible para administradores.

Para crear un proyecto:

1Entre a Proyectos.

2Presione Nuevo proyecto.

3Capture el titulo del proyecto.

4Seleccione uno o varios investigadores.

5Seleccione el departamento.

6Seleccione colaboradores si aplica.

7Defina el estado.

8Defina la prioridad.

9Seleccione la fecha limite.

10Presione Guardar proyecto.

Para editar un proyecto:

1Entre a Proyectos.

2Busque el proyecto.

3Presione el boton de editar.

4Modifique la informacion necesaria.

5Guarde los cambios.

Notas importantes:

  • El administrador puede asignar varios investigadores.
  • El administrador puede asignar cualquier cantidad de colaboradores.
  • El primer investigador seleccionado se toma como responsable principal para compatibilidad con vistas anteriores.

7. Detalle de proyecto

Al entrar a un proyecto se muestra una pantalla con dos zonas principales:

  • Informacion general del proyecto.
  • Historial de investigacion.

Informacion general

Incluye:

  • Investigadores asignados.
  • Colaboradores asignados.
  • Departamento.
  • Fecha limite.
  • Estado.
  • Prioridad.
  • Total de archivos subidos.

Gestion de colaboradores

El administrador puede agregar o quitar colaboradores sin limite.

El investigador puede agregar o quitar colaboradores, con un maximo de 3 colaboradores por proyecto.

El colaborador solo puede consultar la informacion del proyecto y subir evidencia si esta asignado.

8. Archivos del proyecto

La seccion Historial de Investigacion permite subir y consultar archivos relacionados con el proyecto.

Subir archivos

Para subir archivos:

1Entre al detalle del proyecto.

2Presione Subir archivo.

3Seleccione uno o varios archivos desde su equipo.

4Espere el mensaje de confirmacion.

Pueden subir archivos:

  • Administradores.
  • Investigadores asignados.
  • Colaboradores asignados.

No se pueden subir archivos si la fecha limite del proyecto ya vencio.

Ver archivos

Para abrir un archivo:

1Localice el archivo en el historial.

2Presione Ver.

Descargar archivos

Para descargar un archivo:

1Localice el archivo.

2Presione Descargar.

El sistema valida que el usuario tenga acceso al proyecto antes de permitir ver o descargar archivos.

Eliminar archivos

La eliminacion de archivos esta reservada para administradores.

9. Encuestas

La seccion Encuestas permite administrar instrumentos de recoleccion de informacion.

Desde esta seccion se puede:

  • Ver encuestas existentes.
  • Crear nuevas encuestas.
  • Editar preguntas.
  • Configurar fechas de inicio y fin.
  • Activar o cerrar encuestas.
  • Consultar resultados, segun permisos.

Las encuestas pueden asociarse a proyectos para recopilar informacion relacionada con una investigacion.

10. Construccion de encuestas

El constructor de encuestas permite definir las preguntas que responderan los participantes.

Una encuesta puede contener diferentes tipos de preguntas, como:

  • Preguntas abiertas.
  • Preguntas de opcion.
  • Preguntas con varias respuestas.

Recomendaciones:

  • Use preguntas claras y concretas.
  • Evite textos demasiado largos.
  • Revise la ortografia antes de publicar.
  • Verifique que las fechas de inicio y fin sean correctas.

11. Responder encuestas

Cuando un usuario responde una encuesta:

1Abre la encuesta desde el sistema o desde un enlace.

2Completa las preguntas requeridas.

3Envia sus respuestas.

4El sistema guarda la participacion.

Algunas encuestas pueden responderse por medio de enlace externo. En ese caso, el participante no necesita entrar al panel principal del sistema.

12. Resultados de encuesta

La seccion Resultados de encuesta permite consultar:

  • Total de participantes.
  • Total de respuestas.
  • Ultima respuesta recibida.
  • Respuestas mas comunes.
  • Lista de participantes.
  • Detalle individual de respuestas.

La pantalla incluye busqueda y paginacion para revisar participantes de forma ordenada.

Esta seccion esta pensada principalmente para administradores o usuarios autorizados.

13. Dashboard general

El Dashboard general presenta una vista ejecutiva del sistema.

Puede incluir indicadores como:

  • Total de proyectos.
  • Total de encuestas.
  • Total de respuestas.
  • Investigadores registrados.
  • Proyectos por estado.
  • Proyectos por prioridad.
  • Actividad reciente.
  • Alertas administrativas.

El dashboard ayuda a revisar rapidamente el estado general de la plataforma.

14. Reportes

La seccion Reportes permite consultar informacion consolidada sobre proyectos, encuestas, participacion y respuestas.

Filtro por proyecto

El usuario puede seleccionar:

  • Todos los proyectos.
  • Un proyecto especifico.

Al cambiar el filtro, las metricas y graficas se actualizan.

Indicadores principales

La parte superior muestra datos como:

  • Encuestas.
  • Preguntas.
  • Participaciones.
  • Promedio por encuesta.

Respuestas por encuesta

Muestra una grafica comparativa de participacion entre encuestas.

Participacion temporal

Muestra como han llegado las respuestas a lo largo del tiempo.

Respuestas mas comunes

Resume las respuestas mas frecuentes por pregunta.

Esta seccion cuenta con paginacion para evitar que la pantalla crezca demasiado cuando existen muchas preguntas.

Participantes recientes

Lista los participantes mas recientes registrados en las encuestas.

Tambien cuenta con paginacion para mantener el panel compacto.

Preguntas, respuestas y graficas

Muestra el desglose detallado de preguntas, respuestas y graficas.

Esta seccion tambien cuenta con paginacion para facilitar la consulta.

Descargar PDF

El boton Descargar PDF genera un reporte imprimible con informacion ejecutiva.

15. Administracion

La seccion Administracion esta disponible para usuarios administradores.

Permite gestionar:

  • Usuarios.
  • Roles.
  • Permisos generales.

Crear usuario

Para crear un usuario:

1Entre a Administracion.

2Presione Nuevo usuario.

3Capture nombre, apellidos, correo y contrasena.

4Seleccione el rol.

5Guarde el usuario.

Roles disponibles:

  • Administrador.
  • Investigador.
  • Colaborador.
  • Visor.

Editar usuario

Permite actualizar informacion del usuario y cambiar su rol.

Eliminar usuario

Permite eliminar un usuario del sistema cuando ya no debe tener acceso.

16. Recomendaciones de uso

  • Cierre sesion cuando termine de usar el sistema.
  • Revise cuidadosamente las fechas limite de los proyectos.
  • Asigne investigadores y colaboradores correctos desde el inicio.
  • No comparta su contrasena.
  • Use nombres claros para los archivos que suba.
  • Mantenga actualizados los estados de los proyectos.
  • Revise los reportes periodicamente.
  • Antes de eliminar informacion, confirme que no sera necesaria.

17. Preguntas frecuentes

No veo todos los proyectos

Esto depende de su rol. Los colaboradores e investigadores solo ven proyectos donde participan. El administrador ve todos.

No puedo subir archivos

Puede deberse a una de estas razones:

  • No esta asignado al proyecto.
  • La fecha limite ya vencio.
  • Su rol no tiene permisos para subir archivos.

No puedo agregar mas colaboradores

Si es investigador, el limite es de 3 colaboradores por proyecto.

Si es administrador, no tiene limite.

No aparece la seccion Administracion

La seccion Administracion solo esta disponible para administradores.

No puedo ver encuestas, dashboard o reportes

Algunos roles tienen navegacion limitada. Los colaboradores normalmente solo ven Mis proyectos.

Un colaborador no ve un proyecto

Verifique que el colaborador haya sido asignado al proyecto.

Un investigador no puede gestionar colaboradores

Verifique que el investigador este asignado al proyecto.

18. Glosario

Proyecto

Registro principal de una investigacion academica.

Investigador

Usuario responsable o participante en la investigacion.

Colaborador

Usuario que apoya un proyecto especifico y puede subir evidencia.

Evidencia

Archivo relacionado con el avance o resultado del proyecto.

Encuesta

Instrumento para recopilar informacion de participantes.

Reporte

Resumen ejecutivo de informacion del sistema.

19. Cierre

Este manual resume el uso general del Sistema de Gestion de Proyectos Academicos. Si alguna pantalla cambia o se agregan nuevas funciones, el manual debe actualizarse para conservarlo alineado con el sistema.
